# hyperlab-sh/homebrew-tap

Homebrew tap for [homebot](https://homebot.sh), a dotfiles manager for people
who won't remember to run it.

```sh
brew install --cask hyperlab-sh/tap/homebot
```

The cask in `Casks/` is written by homebot's release workflow on each final
release. Don't edit it by hand; changes are overwritten by the next release.
Report problems at https://github.com/hyperlab-sh/homebot/issues.
